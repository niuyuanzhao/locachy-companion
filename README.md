# LOCachy companion

Programs that run on other operating systems and work with LOCachy. Each program has its own directory and its own README.

| Program | Platform | Directory |
|---|---|---|
| extdisplay-sender | macOS | `extdisplay-sender/macos` |

The protocol is defined by the LOCachy receiver `extdisplay` in the main LOCachy repository (`src/tools/EXTDISPLAY.md`, identity `locachy-extdisplay-v1`).
